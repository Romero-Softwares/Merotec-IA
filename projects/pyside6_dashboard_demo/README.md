# EcoCiclo — demonstração PySide6

Pequeno dashboard desktop para acompanhamento de compostagem. Inclui cartões de métricas, gráfico de evolução, gráfico circular, lista de tarefas, filtros e botões com ícones nativos.

## Executar

```powershell
venv\Scripts\python.exe -m pip install -r projects\pyside6_dashboard_demo\requirements.txt
venv\Scripts\python.exe projects\pyside6_dashboard_demo\app.py
```

O botão **Registrar lote** aumenta a produção simulada e atualiza os indicadores.
